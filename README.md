# Beatriz — Advocacia

Projeto de presença digital para apresentar o trabalho da Beatriz na área jurídica.

## Sobre o projeto

A proposta é oferecer uma página institucional direta, com apresentação profissional, informações revisadas pelo escritório e formas de contato claras.

## Situação

A demonstração foi publicada, mas o código-fonte ainda não está neste repositório. As linguagens serão reconhecidas pelo GitHub quando a aplicação for versionada aqui.

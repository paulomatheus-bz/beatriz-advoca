# Beatriz — Advocacia

Projeto de presença digital para apresentar o trabalho da Beatriz na área jurídica.

## Proposta

Uma página institucional direta, com apresentação profissional, informações revisadas pelo escritório e formas de contato claras. O conteúdo deve permanecer fiel aos serviços confirmados pela responsável.

## Situação

A demonstração foi publicada, mas o código-fonte ainda não está neste repositório. O GitHub identificará as linguagens quando os arquivos da aplicação forem versionados.

## Revisão antes de publicar

Conferir nome profissional, áreas de atuação, contatos e textos jurídicos com o escritório. Evitar publicar informações que não tenham sido aprovadas.
